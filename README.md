# disparate-fc-videos

Vídeos finales de **Disparate FC**, un canal de YouTube Shorts de fútbol absurdo de dibujos animados para niños.
Metricool los publica en YouTube desde aquí: cada vídeo de `videos/` tiene un enlace directo.

- Personajes, animación, música y efectos originales. Voces generadas con IA.
- Los sube cada lunes la tarea automática de producción. Antes de subirse, cada vídeo pasa el control de calidad:
  1080×1920, 30-45 s, −14 LUFS y sin destellos.
- El programa que genera los vídeos, el registro de episodios y los informes de cada semana están en Google Drive › «Disparate FC».

Para que Metricool pueda descargar los vídeos, este repositorio tiene que ser **público**.
